# dashboards

Screenshots of /hermes-dashboard output at meaningful moments.

The dashboard HTML file is project-specific and contains stack
details (database URLs, integration names, internal repo paths in
some cases). Screenshots are the shareable form.

Worth capturing:
- First dashboard render after /hermes-dashboard is run
- Dashboard at end of a major phase (shows the trajectory)
- Dashboard with a CONDITIONAL/BLOCK verdict visible
- Dashboard showing Hermes overhead spike (>20%) — diagnostic value
- Dashboard showing Hermes overhead low (<10%) — discipline success

A captured dashboard screenshot should be accompanied by a short
markdown file with:

- Date and project
- What's notable in this view
- Any cross-references to session closures or gate reviews that
  produced the state being shown
