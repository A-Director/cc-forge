# session-closures

Hermes session-end summaries — what gets written when /compact runs.

These are the highest-density single artifacts in cc-forge. A good
session closure includes:

- Commits made this session (with SHAs and ticket references)
- Conditions ticked / tasks completed (with persona attribution)
- Tests added or moved
- Decisions closed (ADR references)
- What's deferred and why
- The honest "next moves" with a recommendation

A weak session closure says "good progress today, lots done." A strong
one tells the next session exactly what to pick up from and what's
been parked.
