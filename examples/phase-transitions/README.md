# Phase transition captures

Real `/hermes-phase-gate` outputs — full-panel reviews advancing a
project between PDLC phases (MVP → Beta, Beta → Pilot, etc.). One
file per transition, named `YYYY-MM-DD-<project>-phase-<N>-to-<N+1>.md`.

Goal: show what a phase transition actually looks like end-to-end —
exit-criteria check, full-panel findings, the dedicated
`chore(phase): advance to Phase N+1` commit, CHANGELOG entry. Rare
event by design — expect a small sample.
